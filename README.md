## 🎯 What is FitLog?

**FitLog** is a dark-themed workout companion built with Next.js. It provides an easy way to discover exercises, build a daily workout plan, and keep track of important workout information such as duration, calories, difficulty, and target muscles.

The interface is designed to stay clean and focused, giving users quick access to the information they need while working out.

---

## 🌟 Highlights

| Feature | Description |
|---------|-------------|
| 🏋️ **Exercise Discovery** | Explore workouts organized around different muscle groups and training categories. |
| 📅 **Daily Workout Builder** | Select exercises and create a personalized routine for the day. |
| 🔥 **Calorie Monitor** | Calculate and display estimated calories burned based on your selected workouts. |
| ❤️ **Favorites** | Keep your preferred exercises saved for quick access later. |
| 🔎 **Sort & Filter** | Easily organize workout data using different metrics such as calories, duration, and ratings. |
